Hermes Mobile — нативный Android-клиент для Hermes Agent, который живёт на вашем сервере.

Это не обёртка над браузером: приложение само ходит в HTTP API Hermes и держит WebSocket, поэтому ответ приходит по токенам, вызовы инструментов и их результаты видны в ленте, а долгий прогон переживает погашенный экран.

Нужен свой сервер Hermes. Без него приложению некуда подключаться — это клиент, а не облачный сервис.

Что умеет:

<b>Сеансы</b> — список с фильтром по проекту, архив, поиск по всей истории, отметки прочитанного.<br>
<b>Чат</b> — потоковый ответ по WebSocket, вызовы инструментов прямо в ленте, Markdown и подсветка кода, картинки и файлы.<br>
<b>Управление прогоном</b> — отправить, остановить или «steer»: дописать агенту указание по ходу, не убивая прогон. Несколько сообщений в очередь.<br>
<b>Слэш-команды</b>, смена модели и профиля прямо из чата.<br>
<b>Уведомления</b> — статус «работаю», готовый ответ с текстом и запрос ввода отдельной карточкой высокого приоритета. Live Update на Android 16+ и виджет на домашнем экране.<br>
<b>Фон</b> — опциональный foreground-сервис, который доводит прогон до конца и присылает ответ, даже если приложение закрыто.<br>
<b>Файлы</b> — отправка любых файлов, не только картинок.<br>
<b>Kanban</b> — доска Kanban WebUI в мобильном виде: колонки как вкладки, карточка перетаскивается долгим нажатием.<br>
<b>Голосовой ввод</b> в поле ввода.

Требования: Hermes Agent 0.23.x на сервере с включённым webapp, HTTPS снаружи и вход под той же учётной записью, что в веб-панели Hermes. Пароль не хранится — только cookie сеанса.

Свои обновления выключены по умолчанию: приложение умеет тянуть сборки только со своего сервера, поэтому это осознанный выбор, а диалог предупреждает об этом до включения. Пока выключено, ничего не скачивается и не ставится.

Исходный код: https://github.com/r1290z/hermes-android

Клиент не связан с Nous Research; Hermes Agent — их проект.
